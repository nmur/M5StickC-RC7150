# M5StickC-RC7150

Minimal, open-source firmware for the **M5Stack M5StickC Plus SE**, implementing
the Philips RC7150 Dealer Service Tool's **ALIGN** function over infrared.
The target television is a **Philips 34PT5793/79R, A8.0A-AA chassis**.

Just aim at the TV and press the A button to open SAM.
